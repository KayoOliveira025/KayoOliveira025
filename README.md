O projeto faz parte do meu processo de desenvolvimento técnico e busca transformar conhecimentos teóricos em uma aplicação funcional.

## Tecnologias utilizadas

- Python 3
- Estruturas condicionais
- Estruturas de repetição
- Variáveis e tipos de dados
- Listas
- Funções
- Entrada e saída de dados
